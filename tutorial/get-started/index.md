# Get up and running

Welcome. You are in a **lab**: a lesson and a real terminal, side by side.
The terminal is a private machine that is yours for the next few minutes.
Nothing you do here can break anything, and it is all thrown away when you finish.

## The page

- **The terminal** is on the left. Click in it and type, as in any terminal.
- **This lesson** is on the right.
- **The bar at the top** shows the lab's name, whether the terminal is connected, and how long you have been here.
- **The line between them** can be dragged, to give the lesson or the terminal more room.

## Your first command

Below is a code block.
It has a **Copy** button, to copy the command, and a **Run** button, which types the command into the terminal and runs it for you.
Press **Run**:

```shell
echo "Hello from my first lab"
```

The terminal answered with the greeting.
That is all a code block does: it saves you from typing, and it never hides what it is about to run, because the command is right there.

## Finishing

At the bottom of the lesson is **Complete lab**.
It shuts the machine down and ends the lab.
It waits a couple of minutes at first, so that a lab is not ended by accident, and the lock beside it lets you finish sooner.

That is everything you need to take a lab.
