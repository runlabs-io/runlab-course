# Start in a layout

This lab's terminal opens in two panes. The top pane is named edit. The bottom pane is named run.

Refreshing the page joins the same session, so the panes stay as they are.

## Edit

```shell panel="edit"
echo edit
```

## Run

```shell panel="run"
echo run
```

## Show a file

A link can show a file in a pane. This one shows `data/hello.txt` in the run pane.
